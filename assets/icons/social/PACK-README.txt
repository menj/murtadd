MINIMALIST SOCIAL & PLATFORM ICONS PACK
========================================

43 single-color, minimalist icons for social media platforms,
scholarly/identifier services, and major websites. Every icon is a
clean monochrome glyph with no gradients, shadows, or extra detail —
just the mark. Every SVG in the pack shares the same viewBox
("0 0 24 24") and every PNG is the same 512x512 transparent canvas,
so any icon can be dropped in next to any other at a matching size
with no per-icon rescaling.

INCLUDED (43)
-------------
Facebook, Instagram, X (Twitter), LinkedIn, YouTube, TikTok,
Pinterest, Snapchat, WhatsApp, Telegram, Reddit, Discord, Threads,
WeChat, Tumblr, Twitch, Vimeo, Medium, Behance, Dribbble, Mastodon,
Bluesky, LINE, Signal, GitHub, Spotify, Goodreads, Wikidata,
Wikipedia, Academia.edu, Quora, Issuu, Substack, Flickr, Scribd,
GTribe *, ORCID, SoundCloud, WordPress, ISNI †, VIAF †, Suno †,
OCLC Entities †

* GTribe is PNG only (png/black/gtribe.png, png/white/gtribe.png),
  512x512, transparent background — no svg/gtribe.* file. It isn't
  in Simple Icons or Font Awesome, so this one was built by hand:
  cropped from the logo file you supplied, isolated to just the "G"
  mark (dropping the "TRiBE" wordmark, to match how every other icon
  in this pack is a mark-only glyph), and cleaned into a flat
  silhouette. A vector trace was attempted but kept rendering with a
  clipped edge, so it's shipped as a high-res PNG instead rather than
  a broken SVG. Source rights are whatever you already had for the
  logo file you uploaded — this pack doesn't add any new license
  claim over it.

ORCID, SoundCloud, and WordPress were added from your uploaded
favicons (ORCID.ico, soundcloud.ico, profiles_wordpress_org.ico).
Rather than trace those low-res favicons directly, all three were
matched to existing open-licensed vector marks of the same brand
mark (see LICENSE & ATTRIBUTION), recolored to pure black/white and
re-fit to this pack's 24x24 viewBox.

† ISNI, VIAF, Suno, and OCLC Entities were also added from your
uploaded favicons, but none of the four have a separate "icon" the
way a social platform does — ISNI, VIAF, and Suno are wordmark-only
logos with no standalone mark, and OCLC Entities' identity is a
multi-color ring cluster, not a single silhouette. None of the four
are in Simple Icons or Font Awesome either. So — same approach as
GTribe — each was rebuilt by hand as a flat, single-color version
that fits this pack's style instead of upscaling the small source
favicon:
  - isni.svg / isni.png    — the wordmark redrawn as a solid glyph
  - viaf.svg / viaf.png    — the wordmark redrawn as a solid glyph
  - suno.svg / suno.png    — the wordmark redrawn as a solid glyph
  - oclc-entities.svg/png  — the three overlapping rings from the
                              original mark, redrawn as flat monochrome
                              outlines (color and gradient dropped,
                              proportions kept close to the source)
None of these four claim to be the brands' official logo artwork —
they're original redraws in this pack's flat style, based on what
your favicon showed. Swap in the brand's own SVG if you need one
that's pixel-exact to their current guidelines.

A NOTE ON CONSISTENCY
----------------------
The original 35 vector icons in this pack (Simple Icons) already
shared a "0 0 24 24" viewBox — standard practice for that library.
Two exceptions from the original set, LinkedIn and Scribd (sourced
from Font Awesome, which ships its own icons at "0 0 448 512" and
"0 0 384 512"), have now been re-fit to the same "0 0 24 24" system
as everything else — same artwork, just re-expressed in matching
units. The seven additions from these last two rounds (ORCID,
SoundCloud, WordPress, ISNI, VIAF, Suno, OCLC Entities) were built
straight into that system, so the full 42-file SVG set is now on
one shared viewBox, and all 43 PNGs render at the same 512x512 with
no per-icon size or padding inconsistency.

FOLDERS
-------
svg/black/   vector icons, black fill      -> for light backgrounds
svg/white/   vector icons, white fill      -> for dark backgrounds
png/black/   512x512 raster, black, transparent background
png/white/   512x512 raster, white, transparent background

Use the SVGs wherever you can — they're crisp at any size, and the
files are only ~0.3-2KB each (a little more for the wordmark ones),
so a full row costs almost nothing in page weight (good for Core Web
Vitals / LCP). The PNGs are there as a fallback for tools or builders
that don't accept SVG.

USAGE
-----
- Files are named after the platform (e.g. instagram.svg,
  instagram.png) so you can drop them straight into a footer or
  "follow us" block.
- To recolor an SVG: open it in a text editor and change the
  fill="#..." value, or inline the <svg> in your HTML and set
  `fill: currentColor` to control it from CSS.
